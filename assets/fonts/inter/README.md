# Inter

Variable Latin normal and italic fonts, including weight and optical size axes.

- Source package: `@fontsource-variable/inter@5.3.0`
- Upstream: https://github.com/rsms/inter
- License: SIL Open Font License 1.1, included in `OFL.txt`.

The font files are redistributed without modification. Chinese text uses the native sans-serif fonts listed in the site stylesheet.
